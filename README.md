# Thread Buddy - Metric thread calculator
Android wrapper (Capacitor) for https://threadcalculator.lovable.app

1. Create a new GitHub repo and upload everything in this folder (including the .github folder).
2. Open the repo > Actions > "Build APK" > wait ~5 min (or click "Run workflow").
3. Open the finished run, download the "Thread-Buddy-APK" artifact, unzip it to get app-debug.apk.
4. Copy the APK to your Android phone and install it (allow "install unknown apps").

Icon + splash live in resources/ (replace the PNGs there to change them).
Splash duration: launchShowDuration in capacitor.config.json (milliseconds).
